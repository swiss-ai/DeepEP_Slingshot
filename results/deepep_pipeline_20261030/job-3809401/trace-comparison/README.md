Five qualified captures, each eight ranks and three iterations per operation. Ordinary latency uses three separate timing repeats. Disabled and enabled results use instrumented builds. Heatmap values are medians of intervals clipped to the latest-finishing role warp on each rank. Missing stage events contribute zero; overlapping categories are not additive. Arrival wait is the dispatch forwarder, while the other dispatch columns describe the sender. No cross-node clock alignment or NIC wire duration is assumed.
